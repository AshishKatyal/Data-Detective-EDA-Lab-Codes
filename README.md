# Python EDA Lab Codes

This repository contains 10 interactive Python scripts designed for teaching Exploratory Data Analysis (EDA).

## 📚 Topics Covered

1. Data Types in Python
2. Outlier Detection (Z-score & IQR)
3. Variance Visualization (Box Plots)
4. Histogram vs KDE
5. Outlier Detection Case Study
6. Missing Data Analysis
7. Correlation Matrix
8. A/B Testing
9. Sampling Techniques
10. Misleading Data Visualization

## 🎯 Purpose
These scripts are designed for:
- Classroom demonstrations
- Student hands-on learning
- Data Science beginners
